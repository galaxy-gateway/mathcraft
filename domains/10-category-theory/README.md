# 10 — Category theory

Functors, monads, limits — the structural language of mathematics. TypeScript's
structural type system makes categorical constructions unusually readable.

**Planned concepts:** category interface, `Functor` and `Applicative` type
classes, `Monad` (with `Identity`, `Maybe`, `List`, `State`), natural
transformations, limits as universal cones, Yoneda lemma sketch.
