# domains/

The classical mathematics taxonomy. Subdirectories are numbered for stable
ordering.

| Path                              | Domain                                 |
| --------------------------------- | -------------------------------------- |
| `00-foundations/`                 | Logic, set theory, proof techniques    |
| `01-number-theory/`               | Number theory — **flagship deep-dive** |
| `02-algebra/linear/`              | Linear algebra — **flagship deep-dive** |
| `02-algebra/abstract/`            | Groups, rings, fields, modules         |
| `02-algebra/commutative/`         | Ideals, Gröbner bases                  |
| `02-algebra/homological/`         | Chain complexes, Ext, Tor              |
| `03-analysis/real/`               | Real analysis                          |
| `03-analysis/complex/`            | Complex analysis                       |
| `03-analysis/functional/`         | Functional analysis                    |
| `03-analysis/numerical/`          | Numerical methods                      |
| `04-geometry/euclidean/`          | Classical Euclidean geometry           |
| `04-geometry/differential/`       | Differential geometry                  |
| `04-geometry/algebraic/`          | Algebraic geometry                     |
| `04-geometry/computational/`      | Convex hulls, Voronoi, Delaunay        |
| `05-topology/point-set/`          | Point-set topology                     |
| `05-topology/algebraic/`          | Algebraic topology                     |
| `05-topology/computational/`      | Computational topology / TDA           |
| `06-discrete/combinatorics/`      | Counting, generating functions         |
| `06-discrete/graph-theory/`       | Graph theory — **flagship deep-dive**  |
| `06-discrete/order-theory/`       | Orders, lattices                       |
| `07-probability/measure/`         | Measure-theoretic probability          |
| `07-probability/distributions/`   | Distributions and sampling             |
| `07-probability/stochastic-processes/` | Markov chains, martingales        |
| `07-probability/statistics/`      | Frequentist and Bayesian statistics    |
| `08-optimization/convex/`         | Convex optimization — **flagship**     |
| `08-optimization/combinatorial/`  | ILP, branch-and-bound, matching        |
| `08-optimization/stochastic/`     | SGD, bandits, simulated annealing      |
| `08-optimization/optimal-transport/` | Wasserstein, Sinkhorn               |
| `09-information-theory/`          | Entropy, coding, compression           |
| `10-category-theory/`             | Functors, monads, limits               |
| `11-dynamical-systems/`           | Chaos, bifurcations                    |
| `12-mathematical-physics/`        | Mechanics, tensors, QM basics          |

See [`ROADMAP.md`](../ROADMAP.md) for what's built and what's planned.
