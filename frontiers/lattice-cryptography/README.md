# Lattice cryptography

Public-key cryptography based on the hardness of lattice problems. Candidate
standards for the post-quantum era.

## Concepts

| -------------------- | --------------------------------------- |
| [`lwe/`](./lwe/)     | Toy Learning-With-Errors encryption     |
